# Support

- **Questions and bugs:** open an issue on [php-io-extensions/miniaudio](https://github.com/php-io-extensions/miniaudio/issues). Include `php --ri miniaudio`, your OS, PHP version and build (NTS or ZTS), and the smallest script that shows the problem.
- **How a miniaudio call behaves:** the [miniaudio documentation](https://miniaud.io/docs/) and the comments in [`lib/miniaudio/miniaudio.h`](lib/miniaudio/miniaudio.h) are the reference; this extension adds only what the README's API section describes.
- **Security problems:** see [SECURITY.md](SECURITY.md); do not open a public issue.
