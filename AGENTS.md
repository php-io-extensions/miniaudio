# Agent guidance — php-io-extensions/miniaudio

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, the generator or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1 at miniaudio 0.11.26** (tag `0.11.26`, commit `877ea4a7c2601c7b0f2a44e83dfac42e6470fea6`). Function, struct, enum and constant names are the C names. No defaults, no composites. Not bound: `ma_malloc`, `ma_calloc`, `ma_realloc`, `ma_free`, `ma_aligned_malloc`, `ma_aligned_free`, `ma_log_postv`. Everything else (924 functions) is.
3. **Upstream is copied unchanged** into `lib/miniaudio/` (`miniaudio.h`, `miniaudio.c`, `LICENSE`, `extras/stb_vorbis.c`). Never edit it. `src/miniaudio_impl.c` is the one translation unit that compiles it. A new miniaudio only from a new upstream tag: replace `lib/miniaudio/`, re-extract, regenerate, fix what the generator reports, bump the version.
4. **The binding is generated.** `clang -Ilib/miniaudio -Xclang -ast-dump=json -fsyntax-only tools/ast.c | php84 -d memory_limit=-1 tools/extract.php > tools/api.json`, then `php84 tools/generate.php` (prints `bound N, pending 0`; any pending function or unclassified field is a decision to add to `tools/bindings.php` or the generator), then `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`. Commit `tools/api.json`, the stubs, the `*_arginfo.h` and `src/gen/` together. Never hand-edit generated files. `src/manual.c` and `src/callbacks.c` / `src/backends.c` hold the functions with no generic shape.
5. **Value structs** are final classes, one typed property per C field in order. **Handle classes** hold the C struct in place (64-byte aligned, never moves); `new` is storage, `_init` makes it live, free uninitializes it, its plain fields read as live read-only properties. A handle another handle points into is kept alive by it and is uninitialized after it.
6. **Sizes come from C.** Every PCM buffer's size is `[count, unit]` over the converted arguments with an overflow check; a short input string is a `ValueError`; a null handle returns `MA_INVALID_ARGS` before any size reads it. A buffer miniaudio reads later is retained by the handle that points at it.
7. **Threads never enter PHP.** miniaudio's threads queue callbacks to the owning PHP thread and wait until served or a deadline passes (then the no-op result applies). The owner serves from `zend_interrupt_function` and while calls in `BLOCKING` (and every uninit) run on a helper thread. A thread-owning handle from before `fork()` is an `Error` in the child. Request end uninitializes every live handle, newest first.
8. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`. On the Pi, copy the tree with `fnk` (set `COPYFILE_DISABLE=1` on the Mac `tar` so no `._*` files reach gen_stub) and `./install-debian-trixie.sh`. Pest at `-d memory_limit=128M`, with `XDEBUG_MODE=off` for any timing. Tests use the null backend only; never open real audio hardware in a test. Gate a commit on the suite's exit code.
9. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`.
10. **Version** is `PHP_MINIAUDIO_VERSION` in `php_miniaudio.h`: 0.11.0. `os-families`: linux, darwin.
